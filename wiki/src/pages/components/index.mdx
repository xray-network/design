# Components

Components are the primitives: single controls you build screens from, such as buttons, inputs, menus and tables.
Each one comes as HTML and CSS, with a small vanilla controller where it needs behavior, and as a React component
built on the same markup. Your agent copies the ones you need into your UI folder, where they become your code.

Every page has a live demo in both versions, the source of each, and the component's contract: anatomy, states,
accessibility, motion and what you can safely change.
