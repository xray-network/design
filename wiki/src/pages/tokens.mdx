# Tokens

Every color, size and timing in XRAY/DESIGN is a token. They are listed in the header of
<a href="/design/DESIGN-PROTOCOL.md"><code>DESIGN-PROTOCOL.md</code></a> with their final values in both themes, and implemented as CSS
custom properties in `core/tokens.css`. The kit check fails if the two ever differ.

Components read **semantic** tokens (colors, type, space), never the palette. To rebrand, override a few semantic
tokens in your own stylesheet, loaded after `core/tokens.css`. Values that differ by theme are written with
`light-dark()`, so a token follows the page's theme, or any subtree with `data-theme="light"` or `data-theme="dark"`.

below. Reduced motion sets every duration to 0.
