# Blocks

Blocks are finished screen sections, such as a tab bar, a table with its search and pages, an order book or a
checkout, built from [components](/concepts#components-blocks-and-screens). Some also hold a chart or a motion
pattern. Your agent copies a block together with everything it uses, so you can start a screen from it and adapt
it.
