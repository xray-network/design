# Charts

Charts are drawn from a plain data table by a small controller, on a frame they all share: no charting library, and
the same rules on every GUI target. A project that already draws charts with a library keeps it and sets it up to
look and read like these. The rules are in the [design protocol](/protocol), section 16.
