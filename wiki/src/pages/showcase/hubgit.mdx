# Hubgit App

<AppShowcase id="hubgit" />

A code host in three screens. Code is Stats, a List of files and a ShareBar of languages; a pull request is Steps for its checks over the Comments block, where commits sit between the comments as quiet lines; Insights is a Heatmap of commits by weekday, a StatusStrip of the last runs and a ChartCard with a StackedAreaChart.

The app is one static HTML page on the kit's own CSS and controllers: every screen is a section, and the tabs in
the TopBar block move between them with the Screen pattern. It is designed 740px wide and is framed here at 640px.
**Open** shows a screen on its own; **Copy prompt** gives your agent that page to rebuild in your project.
